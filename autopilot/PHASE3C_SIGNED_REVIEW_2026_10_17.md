# FlowMinute Lab — Phase 3C: separated, signed review evidence

**Software CI checkpoint, 17 October 2026. Not a live reviewer service, release approval or public publishing.**

## Implemented

`autopilot/signed_review_gate.py` takes the Phase 3B `EvidencePacket` generated by real local FFprobe/FFmpeg file inspection and evaluates a detached four-review record bundle. The four required dimensions are `media_visual`, `audio_language`, `source_accuracy`, `asset_rights`.

For each review, the signature covers the full canonical `ReviewClaim`: episode ID, Phase 3B packet SHA-256, inspected final MP4 SHA-256, measured narration SHA-256, review dimension, reviewer identity and key ID, PASS/REJECT, assessment/expiration timestamps, evidence-file digests, bounded notes, and unique receipt ID.

The verifier uses **Ed25519** public-key signatures against a **separate, trusted and externally provisioned allowlist**. Review receipts cannot invent their own trusted keys, change the video after review, replay to another episode, pass an expired signature, or skip any of the four distinct required review dimensions. An explicit creator/publisher-exclusion identity set is required. Repeated reviewer identities, unauthorized roles and a signed REJECT all block progress.

The verifier NEVER holds a real private signing key, saves a token, calls an upload endpoint, or changes a release state. A successful bundle returns only `SIGNED_RECORDS_PRESENT_AWAITING_EXTERNAL_APPROVAL` and explicitly `publishing_authorized=False`. `human_review_observed_by_software=False`, `license_legality_verified_by_software=False`, `media_content_verified_by_software=False`.

**Trust boundary:** A mathematically valid signature proves that the holder of the trusted private key signed the receipt. It **does not** prove the signer is a human, watched the footage, listened to Hindi narration, confirmed every asset's commercial rights, or reviewed source accuracy. Reviewer enrollment, protected key custody, session authentication and genuine review evidence are **NOT deployed**. The current review packet is staging metadata and is not independent legal clearance.

## Verified CI evidence

- [Full software suite: 241 tests + 6 subtests, PASS](https://github.com/Tirthanand17/taskless-lab/actions/runs/39039521037).
- `autopilot/test_signed_review_gate.py`: 20 isolated security and workflow cases, using only disposable Ed25519 keys created inside tests.
- Includes independent four-review success, missing review, tampering with either measured media hash or the rights manifest, invalid or revoked key, wrong role, altered signature, age and expiry, signed rejection, absent creator/publisher exclusion, duplicate reviewer/receipt, cross-episode replay, and malformed evidence references.
- Python's public software CI now installs the bounded free open-source `cryptography>=44,<47` package to exercise Ed25519 support. No service connection or account credentials are added.
- The sample media/rights reviewed in tests are synthetic and **not actual user media or legally licensed commercial assets**.

## Before production review is possible

1. Owner-approved reviewer identity and key issuance, with reviewer public keys pinned in an authenticated private Cloudflare/D1 registry rather than supplied in request data; never store private keys in GitHub, public Workers, AI prompts or video files.
2. Separate human/verified-reviewer interface for reviewing the real MP4 and audio, checked license text, subtitles and instructional source claims; preserve auditable evidence, with explicit reject/escalate controls.
3. Protected signing ceremony tied to real user auth and a retained reviewer receipt; no agent can forge a manual review or overwrite an unfavorable outcome.
4. Cloud durable artifact store, upload/processing checks and one authoritative idempotent ledger with immutable receipts.
5. Representative full-length rendered Short and long video, independently inspected audio, video, caption timing and rights in both languages; verify genuinely free compute/storage and provider policies.
6. Resolve Google External/Testing OAuth seven-day refresh expiration and get separate explicit approval for the first private YouTube upload pilot.

**Next engineering phase:** Phase 4 single-writer cloud metadata and release-state integrity, initially as a no-deploy migration/design plus local tests. Reuse the existing private Cloudflare D1 and control/ledger.py; do not create a competing production publishing ledger.
