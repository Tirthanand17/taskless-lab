# FlowMinute Lab — fixed synthetic subprocess worker termination (offline proof)

**19 October 2026 | Existing public DRAFT PR #5 | No production workers**

Previous task-generation fencing rejected stale Handoffs and heartbeats after a task's failure, expiry or quarantine, but **did not terminate the worker executable**. A synthetic child could keep burning compute after the master had cancelled its lease or reassigned a video slot.

This offline-only improvement adds `autopilot/agent_staging_process_supervisor.py` and fixed `autopilot/phase1_synthetic_subprocess.py`. The coordinator gains a read-only `is_current_worker_lease` check of original task owner, active video slot, generation and expiry against the local SQLite host clock. The supervisor runs ONLY a fixed repo-owned, stdlib synthetic probe through `subprocess.Popen` using `sys.executable -I -B`, no shell, no arbitrary executable/commands or keys/DB credentials passed by environment. It polls the coordinator's current lease while the process runs, forcibly terminates and reaps the child when lease ownership is lost or a fixed max-8-second local deadline elapses. Output is bounded and verified as explicitly `SYNTHETIC_STAGING_PROBE`, never persisted as a typed task completion, video, independent review or upload permission. An individual fixed child never forks descendants.

No-secrets, no-network Linux GitHub regression tests verify normal synthetic subprocess exit, stale lease refusing to spawn, a task retry terminating and reaping its running child, a three-failure script quarantine terminating a parallel in-flight hooks child, hung-worker timeout, nonzero child exit never completing tasks, and invalid mode/missing sandbox rejection.

**Important limitations:** this fixed local child termination requires the supervisor to be **running and polling**; there is no background autonomous daemon or deployment. It does **not** guarantee killing a real external model/provider task, process descendants, remote workers, or services after a host crash. Subprocess and coordinator still share an OS user, so there is NO hardened DB credential/file isolation. Lease checking is not a replacement for task JWT/OAuth/authenticated remote identities or independently trusted database time.
