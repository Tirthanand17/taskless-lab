# Phase 3 — SHA-bound final AAC signal screen, no release authorization

**19 October 2026 | Existing public Draft PR #5 | Offline QA only**

Prior source-locked PCM WAV checks cannot establish that the final H.264/AAC MP4 actually contains the intended usable audio. The new `autopilot/cloud_muxed_audio_screen.py` checks an *existing* file only, pins its SHA256 and size to a previously inspected full-media `TechnicalFullHDObservation`, extracts five spread 4096-sample windows of decoded AAC through fixed local FFmpeg arguments (no shell/network/writes), applies existing FFT pure-tone detection and conservative silence/clipping/DC checks, then rehashes the MP4 to reject media swapped while sampling.

The module's purpose is strictly technical placeholder **rejection**. Even deterministic random noise may pass this gate and is not speech. A good AAC signal does not prove actual Hindi/English words, two different natural-sounding short narrators, word-level subtitle timing, licensing, identity, consent, independent visual/factual review, or release authorization. `summarize_muxed_audio` always carries those content-rights blockers for all three 42s/42s/432s lanes. It contains no YouTube/upload/publisher capability or account access. The adapter expects prior full-length H.264/AAC observations; its trust remains local and unsigned.

Nine no-secrets unit tests use fixed synthetic PCM and **mocked FFmpeg output** only, not real full-HD narration, to check pass-as-technical noise, rejection of pure sine/silence/clipping/DC placeholders, fail-closed truncated PCM/decoder errors, byte alteration, bad path/SHA/false rights flags, numerical features, three-lane blocker preservation, duplicate/mismatched receipts, and absence of media output files. Existing Cloud Scout and Content Quality Gate run these tests. No separate high-cost render job or external provider/voice download.

Still outstanding: actual full-duration original H.264/AAC videos plus real rights-cleared bilingual speech, independent authenticated human listening/transcription review, speech-synced SRT and actual private zero-cost render capacity; cloud/OAuth upload and scheduled publishing remain explicitly unauthorized. **21 production acceptance subphases across six unfinished major phases remain OPEN**. Both PR #4/#5 DRAFT/unmerged; no Nirala/laptop, external service, billing, OAuth or YouTube mutation. Recurring infrastructure budget **₹0**.
