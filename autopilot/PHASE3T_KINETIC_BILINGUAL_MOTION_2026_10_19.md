## What is now implemented and what is not

Original 42-second EN and 44-second HI AI-agent approval Shorts were previously drafted in content/production-packs/2026-10-20-gemini-agent-control.json. Their first three teaching beats now have a reusable REAL per-frame animated motion-preview implementation, autopilot/oct20_kinetic_motion_preview.py.

It draws a custom midnight navy/cyan/teal branded 432x768 layout with layered moving cards, perspective-like extrusion, glowing atmospheric parallax, pulsing edges, simulated depth, and progressing scene text. The human approval panel remains locked at all times. ALL Hindi-facing interface copy and step/approval instructions are now in Devanagari; the English storyboard uses independent English copy. The finished frames are original graphical illustrations and are clearly marked an original CONCEPT, not an actual Gemini/grocery checkout screenshot.

The module streams individually generated RGB frames to a preinstalled local FFmpeg process for a bounded 1-12 second silent H264 MP4 excerpt. It verifies output via installed FFprobe: exactly one video track, zero audio, correct dimensions, expected frame count and duration. It refuses preexisting output paths, non-preview episodes, unsupported geometry, missing dependencies or unverified script source state. The output status ALWAYS says:
- full_episode_completed FALSE
- cinematic_3d_mesh_rendered FALSE
- licensed_narration_verified FALSE
- independent_speech_subtitle_alignment_verified FALSE
- media_rights_cleared FALSE
- youtube_upload_authorized FALSE
- youtube_publish_authorized FALSE
