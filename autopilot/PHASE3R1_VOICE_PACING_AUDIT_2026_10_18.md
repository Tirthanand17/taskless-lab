# Phase 3R1 — second-level WAV pacing and waveform damage preflight

**18 Oct 2026. No natural speech / rights / actual publisher integration created.**

We already check (a) PCM16 WAV duration/energy and byte digest and (b) five FFT windows to reject simple sine test tones. This adds (c) independently sampled, **at most 433** one-second-spaced 2048-frame PCM windows over each real 42-second English/Hindi Short or 432-second Hindi long. The screen uses Python's standard library, no external models or APIs. It checks source SHA, duration, PCM16 mono/stereo, leading/trailing/long consecutive near-silent samples, frequent hard PCM saturation and severe DC bias. It uses conservative test thresholds to reject obviously poor recordings, never to approve human authenticity.

\`autopilot/phase3_voice_pacing_audit.py\` provides \`inspect_voice_pacing_candidate\`, which returns technical metadata/counts only, never voice data or private rights docs. \`autopilot/phase3_three_video_handoff.py\` re-runs this gate before admitting a 3-video source bundle and refuses any forged speech or publishing approval in its receipt. \`test_phase3_voice_pacing_audit.py\` uses **real generated synthetic waveform bytes**, not model audio: gross pauses, a small legitimate-style pause, hard clipping, DC offset, short/long duration and SHA mismatch, symlinks. \`test_phase3_three_video_handoff.py\` still mocks media inspectors because it is an orchestration test, and tests source/approval separation.

Limitations: Samples are sparse and do not prove what was said; no ASR, linguistic proof, speaker distinctness, editorial listening, audio-text alignment or legal copyright/speaker consent verification. Real voices with intentional silence may fail this **heuristic**; synthetic complex audio may pass it. On rejection the audio should be **reviewed manually**, not deleted or secretly substituted. Approval stays blocked in all outputs.

A successful full-length HD **synthetic tone** cloud run on previous SHA only proves codecs/frames/decode, not real narrated outputs.
