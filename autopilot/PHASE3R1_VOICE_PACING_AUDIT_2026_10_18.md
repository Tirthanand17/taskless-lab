# Phase 3R1 — second-level WAV pacing and waveform damage preflight

**18 Oct 2026. No natural speech / rights / actual publisher integration created.**

We already check (a) PCM16 WAV duration/energy and byte digest and (b) five FFT windows to reject simple sine test tones. This adds (c) independently sampled, **at most 433** one-second-spaced 2048-frame PCM windows over each real 42-second English/Hindi Short or 432-second Hindi long. The screen uses Python's standard library, no external models or APIs. It checks source SHA, duration, PCM16 mono/stereo, leading/trailing/long consecutive near-silent samples, frequent hard PCM saturation and severe DC bias. It uses conservative test thresholds to reject obviously poor recordings, never to approve human authenticity.

\`autopilot/phase3_voice_pacing_audit.py\` provides \`inspect_voice_pacing_candidate\`, which returns technical metadata/counts only, never voice data or private rights docs. \`autopilot/phase3_three_video_handoff.py\` re-runs this gate before admitting a 3-video source bundle and refuses any forged speech or publishing approval in its receipt. \`test_phase3_voice_pacing_audit.py\` uses **real generated synthetic waveform bytes**, not model audio: gross pauses, a small legitimate-style pause, hard clipping, DC offset, short/long duration and SHA mismatch, symlinks. \`test_phase3_three_video_handoff.py\` still mocks media inspectors because it is an orchestration test, and tests source/approval separation.

Limitations: Samples are sparse and do not prove what was said; no ASR, linguistic proof, speaker distinctness, editorial listening, audio-text alignment or legal copyright/speaker consent verification. Real voices with intentional silence may fail this **heuristic**; synthetic complex audio may pass it. On rejection the audio should be **reviewed manually**, not deleted or secretly substituted. Approval stays blocked in all outputs.

A successful full-length HD **synthetic tone** cloud run on previous SHA only proves codecs/frames/decode, not real narrated outputs. Public PR #5 draft/unmerged, release controller PR #4 draft/unmerged. **21 production acceptance subphases still remain**, with real rights-cleared narration and owner-authenticated YouTube integration not yet available. No connected model/vendor/OAuth, billing, production D1, Nirala/laptop, new cloud storage or upload. ₹0/month recurring infra budget.


## Next Phase 3 quality improvement — scene-level narration presence (18 October 2026)

The prior 1-second WAV waveform checker could permit a near-empty individual authored 3D explanation scene if a few intermittent non-silent bursts interrupted what would otherwise be one long gap. Such missing scene narration damages comprehension while evading both the longest-silence and global-quiet ratio tests. This update **extends the existing Phase 3R1 checker** rather than creating another numbered production phase or consuming an external voice model.

The verifier reads the 42-second Hindi and English Short and 432-second Hindi long original **repository-authored** scene clocks (4/4/24 complete consecutive scenes) and correlates them with the existing per-second 2048-frame PCM16 activity samples from the already hashed complete source WAV. Every scene must contain sampled activity in at least 45% of Short seconds or 40% of long-form seconds, rounding the required count upward, with a narrow original duration tolerance. It reports scene count and minimum observed fraction but **never actual audio, legal documents, words, timestamps, waveform arrays or identifiers**. No new model, HTTP, file creation or voice provider access.

Regression tests show that scattered *two-second* silence gaps in just the first 10-second Short scene or first 18-second long scene now fail despite their prior good overall signal. Ordinary brief pauses, fully active 24-scene long form, original audio digest binding, clipped/DC/tonal detection and zero publishing rights remain intact. The test waveforms contain only synthetic multi-frequency signals and silence, **not natural human speech**.

This screen is an approximate *presence-of-signal* test: music, noise, cloned or synthetic sound can pass, genuinely slow narration/intentional dramatic pauses can fail, and even plausible energy in a scene does not prove speech/word alignment, pronunciation, consent or licensing. Human/independent native-language listening and legally reusable complete Hindi/English recordings are **still absent**. It does not authorize mux, upload, schedule or publish. All 21 existing production acceptance subphases across six incomplete major phases remain, both public PRs stay draft/unmerged, monthly recurring cloud budget ₹0, and no Nirala, new service, charge, OAuth or real YouTube/D1 connection is permitted.
