### Working Python demonstration (actual executable lesson, not a claimed video screen capture)

```python
from csv import DictReader, DictWriter
from io import StringIO

rows = [
    {'product': 'Pen', 'units': '2', 'price': '10'},
    {'product': 'Notebook', 'units': '1', 'price': '30'},
    {'product': 'Eraser', 'units': '4', 'price': '2'},
]

buffer = StringIO(newline='')
writer = DictWriter(buffer, fieldnames=['product', 'units', 'price'])
writer.writeheader()
writer.writerows(rows)

total = 0
for row in DictReader(StringIO(buffer.getvalue(), newline='')):
    total += int(row['units']) * int(row['price'])
print(total)  # 58 fictional example units
```

The code uses fictional rows. Source implementation and synthetic regression checks: `autopilot/examples/flowminute_csv_demo.py` and `autopilot/test_flowminute_csv_demo.py`. The demo is in-memory, no network/files/account access, and produces **58 fictional example units**.
