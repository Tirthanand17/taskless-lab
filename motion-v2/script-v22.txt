Meta launched two new AI models, Wonder and Wonder Full. Which one can you use right now? Here's the catch. Wonder is available through the Meta Model API and Muse Code. Wonder Full is currently for Muse Code subscribers. Meta says Wonder will power more experiences inside the Muse app later, starting with subscribers. So don't assume the new model is already in everyone's Instagram, WhatsApp or Meta AI chats. Their bigger promise is memory plus the ability to keep working on complex tasks.
