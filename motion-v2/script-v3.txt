Excel can change an ID before you touch the file.

Open a CSV with zero-zero-one-two-three and it may become one-two-three. Long identifiers can lose precision or jump into scientific notation.

If a column is an ID, phone number, postal code, or product code, treat it as text.

Import with Data, From Text/CSV, choose Transform Data, set the column to Text, then load.

Digits can be identity, not math.
