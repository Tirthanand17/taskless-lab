Your automation says success. But the dashboard is still showing yesterday's data. Here's the trap: an Office Script running inside a Power Automate cloud flow can return successfully when its refresh call does nothing. Microsoft's documentation says refreshAllDataConnections only refreshes Power BI sources in that flow context. A regular Power Query connection to a CSV may stay stale. Check the source timestamp, the actual row count, and the new invoice before trusting a green flow badge. Success means the script ran, not that fresh data arrived.
