What if ChatGPT built a tiny tool instead of replying with five paragraphs? OpenAI's new GPT-6 Intelligent UI can show interactive controls inside an answer. Imagine splitting a two thousand four hundred rupee bill. Four people? Six hundred each. Six people? Four hundred. Tap a control, see the answer change.
