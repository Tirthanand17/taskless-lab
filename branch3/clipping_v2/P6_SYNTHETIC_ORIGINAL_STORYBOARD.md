# CLIVOX V2 P6 — Source-free original storyboard and EDL draft

**Engineering implementation (2026-11-14).** This prototype creates an original written CLIVOX story arc and strictly timed edit-decision-list (EDL) on **only self-generated synthetic black/white/tone input**. It is NOT a polished video, creator clip, endorsement, monetization approval, human-editor selection, commercial license, permission to publish, or completed P6 milestone.

## Source and hard gates

The previous merged P5 workflow generates a 6-second fixture entirely inside an ephemeral GitHub Actions runner:
- 0–2 seconds: generated black frame, silence
- 2–3 seconds: generated white frame, synthesized tone
- 3–6 seconds: generated black frame, silence

P5 measures candidate timecodes using acoustic RMS rise and grayscale cut evidence; its evaluator compares these against **generated** golden event timing. This P6 module accepts **only** the existing strict P5 detector report as validated by \`validate_detector_report\`, re-evaluates the synthetic event and checks the real A3/P4/P5 **closed** rights policies before creating any plan. The candidate must have both measured signal kinds and cover the known 2–3 second generated event. The P5 detector report is **not cryptographic proof of media provenance or a rights token**; even a forged syntactically valid input cannot grant authorization.

The only input allowed by the CLI is the ephemeral local file \`quarantined-signals-only.json\` in a caller-supplied safe scratch directory, already generated by the P5 workflow. Paths, hashes, source images, audio samples, personal identifiers, real text/transcripts and platform analytics are never included in the output. No network, outreach, downloader, media writer, renderer, uploader, OAuth or contract vault.

## Original CLIVOX editorial draft

The written EDL uses a 1080x1920 **target canvas specification** but creates **no video frames, clips or audio**.

| Draft interval | Generated visual | Original CLIVOX overlay | Purpose |
|---|---|---|---|
| 0–2.0 s | Black | "Watch the scene switch." | Original observation/hook |
| 2.0–3.0 s | White + synthetic tone | "Flash and tone." | True synthetic event cue |
| 3.0–6.0 s | Black | "A sudden cut still needs context." | Original critical payoff/meaning |

The brief and interpretation do not pretend a creator said something. Each shot requires human review; clip/source/publisher rights, actual editor approval, real original commentary quality, human source-context checks, canvas crop checks, real audio, video rendering and YouTube release remain explicitly false. This tiny timeline may not have adequate actual caption reading time; accessibility and pacing need real editorial review later.

The three EDL rows are source-aligned, ordered, nonoverlapping and span exactly the six-second fixture. Schema validation rejects changed words, time gaps/overlaps, modified source labels, inserted speech/voiceprints, fabricated licenses, fake approved editors, external creator URLs, nonzero upload counts, altered source identity and extra keys.
