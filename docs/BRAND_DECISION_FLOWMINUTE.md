# Brand Decision — FlowMinute Lab

## Why the rename

The initial working name overlapped with existing automation and web businesses. Before launch, the public channel identity is changed to **FlowMinute Lab** to reduce brand confusion.

## Public identity

**FlowMinute Lab**

**Tagline:** Less repetitive work. More useful output.

## Promise

Practical workflows that save time using AI, spreadsheets, and Python.

## Naming rules

- Public videos, thumbnails, subtitles, descriptions and channel art use FlowMinute Lab only.
- The GitHub repository name is an internal implementation detail and is not promoted as the channel name.
- No personal name, biography, email address, location or personal account identity is part of the public brand.

## Visual identity

- dark navy background;
- cyan for automation/action;
- green for validated/success states;
- yellow for warnings or key checks;
- red only for mistakes/errors;
- bold, readable mobile-first typography.

## Thumbnail language

Prefer short outcome phrases:
- MESSY → CLEAN
- STOP DOING THIS
- 5 MIN → 30 SEC
- VERIFY THE AI
- AUTOMATE THIS
