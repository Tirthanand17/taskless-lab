# Thumbnail, Hook & Retention Playbook

## Core principle

YouTube evaluates content through appeal, engagement and satisfaction. Packaging gets the click; the opening seconds must immediately prove the promise.

## Shorts

### First frame
- Treat the first frame like a thumbnail.
- Put the problem/result on screen immediately.
- Use 3–7 large words, not a paragraph.
- Prefer visible transformation: messy → clean, slow → automated, wrong → safer.
- Avoid logo intros.

### First 1–2 seconds
- Show the problem or finished result before explaining.
- The first spoken line should match the visual promise.
- Do not start with “welcome back,” “today we are going to,” or channel branding.

### Visual rhythm
- Change the visual idea every 1–3 seconds when it helps clarity.
- Use cursor-like highlights, before/after tables, checklists, counters and validation cards.
- Avoid random stock footage that does not teach anything.

### Captions
- Burn concise captions into Shorts.
- Also ship a UTF-8 timed SRT for accessibility/search.
- Keep caption chunks short enough to read on a phone.
- Keep the lowest caption line clear of mobile UI.

## Long-form thumbnails

YouTube says most top-performing videos use custom thumbnails.

Our template:
- one idea only;
- 2–5 words;
- strong contrast;
- one large object/result;
- no tiny UI screenshots;
- title and thumbnail should complement rather than repeat each other.

Examples:
- **MESSY → CLEAN**
- **STOP DOING THIS**
- **5 MIN → 30 SEC**
- **AI DID THE CLEANUP?**

## A/B testing

For each long-form release produce:
- 3 materially different thumbnail concepts;
- 3 title concepts;
- one searchable variant;
- one curiosity variant;
- one outcome variant.

Use YouTube Studio Test & Compare when available. Judge packaging together with watch-time/retention, not CTR alone.

## Metrics loop

### Shorts
Track:
- stayed to watch;
- average view duration;
- average percentage viewed;
- likes/comments;
- subscribers gained.

### Long-form
Track:
- Home/Suggested CTR in first 24h;
- first 30-second retention;
- average view duration;
- top moments, spikes and dips;
- watch time from impressions.

## Quality rule

Never optimize a misleading thumbnail/title. If viewers click but quickly leave, packaging is not successful.
