# Video V2 Decision

The first uploaded Short is superseded because its visual language looked like a presentation and the captions covered the content.

The new standard is a continuous animated explainer:

- spreadsheet object enters with depth;
- scanner reveals hidden issues;
- cells change in place;
- duplicate row moves to review;
- validation metrics animate into view;
- final state is visibly verified.

The subtitle system is intentionally smaller and lower on screen. It supports the visual instead of competing with it.

The public goal is educational clarity first, retention second, automation third. Automation must not make the videos look templated or mass-produced.
