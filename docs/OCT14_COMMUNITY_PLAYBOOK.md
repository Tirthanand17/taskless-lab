## First actions after long video is published
1. From YouTube Studio, use the official Shorts **Related video** feature to point Shorts 019 and 020 at long_009. Set only after the long video has a verified YouTube video ID and is eligible as the related video. Data API uploads alone do not establish this UI setting.
2. Pin a **genuine topic-specific** question to the long-form comments when YouTube allows it. Never create fake conversation, views, likes or testimonials.
3. For the long video, check the thumbnail and title at mobile preview size; after sufficient impressions, use Studio's supported thumbnail Test & Compare if available. Do not prematurely switch creative from tiny sample sizes.
4. In Shorts editor, consider a Poll or Q&A sticker with relevant user-generated choices only if the editing interface allows it; the existing MP4 cannot be assumed to contain stickers.
5. Respond to actual viewer comments with a helpful detail, then invite one follow-up question. If someone raises a meaningful real question, make the next video a video-reply.

## Metrics to revisit at 24h, 72h, 7d

- Shorts: shown in feed; stayed to watch; engaged views; average percentage watched; comments / 100 engaged views; subscribers gained / 1000 engaged views.
- Long: impressions click-through rate; first-30s retention; average view duration; traffic source; watch hours; end screen/related-video discovery.
- Pair-level: both Shorts' conversion to Long 009; avoid inferring this directly from raw view ratios without attribution.
- Sample-size limitation: initial channel baseline 2 subscribers and 243 views as of early October 13; do not infer causal uplift from three uploads or a single viral spike.
