## Release and experiment contract

- Existing legacy uploads and schedules through 18 November 2026 remain unchanged. **Do not double-schedule** or overwrite an already scheduled video. The next slot is not selected or claimed available without live authenticated YouTube Studio confirmation.
- Do not resume a blind **two Shorts plus one long every day** target during this diagnostic stage. Release a small coherent set only after exact owner media/rights/facts authorization, then check Studio outcomes by each item's actual age.
- Hook within the first two seconds with real result/error, not a CLIVOX/FlowMinute animation. Keep original real software evidence and accessible source-aligned captions. Titles may promise only what their attached real exact MP4 demonstrates.
- Long title candidate: **Why Your CSV Total Is Wrong: 3 Data-Cleaning Bugs in Python**. Show *actual* terminal proof of fictional $2,656.25 before and $1,430.75 after. Do not call it a real customer invoice problem.
- Calc title candidate: **Two Cells Look Equal but Don't Match? Try TRIM in Calc**. Never label the demonstrated software Microsoft Excel.
- If eligible, use YouTube Studio native title/thumbnail A/B testing **only on appropriate long-form videos**, which considers watch time. Shorts are **not** eligible for that native A/B feature; do not invent a Shorts split-test or publish duplicate copies to simulate one.
- The initial pair of candidates is **not** an adequate statistical sample. Existing internal analytics thresholds require **at least five** comparable videos in each group plus qualifying feed exposures/impressions; do not call any measured difference a causal winner.

## Real learning questions

For each owner-authorized upload, privately record Studio data at **24h, 72h and 168h** using `autopilot.branch1_age_matched_learning`. Preserve same video ID/format/series across the three cumulative snapshots, never commit raw Studio CSV. For Shorts, inspect *shown in feed*, *stayed to watch*, engaged views and 3-second retention. For long, inspect 30-second retention, average view duration, qualified watch time, impressions, CTR and genuine subscribers gained. Compare same-age same-format audience cohorts, and change one editorial factor at a time.

**Failure interpretation:** if original Calc hook still receives low choose-to-watch, redesign the actual 0–2 second proof instead of buying more automated rendering credits. If long audiences leave before 30 seconds, move the real Python arithmetic correction earlier and remove boilerplate, never stretch footage. If reach is low despite improved viewing, audit the actual title/cover/topic promise and traffic sources; do not assert hidden restrictions or a shadowban without evidence. If subscriber conversion remains zero, test an explicit series reason to return after viewers demonstrate value.
