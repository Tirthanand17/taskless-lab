## Why existing scheduled videos cannot simply be changed in place

YouTube's official support says [a video cannot be replaced while retaining its URL](https://support.google.com/youtube/answer/55770); the Data API `videos.update` edits metadata fields but not the encoded video bytes, and can mutate privacy/scheduling if used carelessly ([official videos.update](https://developers.google.com/youtube/data/reference/rest/v3/videos/update)). Fixing the rendered circling overlay inside an existing already-uploaded Short requires new source rendering and a new upload ID. **Do not delete, de-schedule, overwrite, or publish original media without a full approved new asset and exact current authenticated owner/channel remote state.** If the old Short has already appeared publicly, preserve that fact; do not imply its public URL can be retroactively fixed. Fail closed on deadlines already past. No automatic destructive account action.

## Reinforcement-style iteration, but with credible metrics and human judgment

`autopilot/creative_iteration_evidence_loop.py` implements a **single-change-per-cycle, evidence-based hypothesis and review loop**, not an unapproved autonomous optimization agent. It requires owner-authenticated YouTube Analytics or attributed Studio exports, separately for similar video topics, two creative versions (old rotating-circle versus new finite subject-specific reveal), 72±12-hour age-matched windows, **at least 6 independently identified videos and 150 engaged views per video in each version**. It tracks average percentage viewed, engaged views/start fraction and average duration, computes honest observational medians, but does not assert causal uplift or auto-publish based on weak signals; missing data produce `NEEDS_AUTHENTIC_COMPARABLE_72H_AUDIENCE_DATA`. A single approved test changes only one creative variable, then waits for fresh measurements. Do not invent engagement or manipulate view counts.

Official YouTube Analytics [metrics](https://developers.google.com/youtube/analytics/metrics) distinguish `engagedViews`, `averageViewPercentage` and `averageViewDuration`; since March 31, 2025, Shorts `views` count starts/replays without minimum watch time ([official reporting revision](https://developers.google.com/youtube/reporting/revision_history)). A higher view count alone is **not** valid evidence that new scenes retained attention. This loop can report observed correlation, never guaranteed virality or a genuine randomized A/B trial.
