# ADR-0060 — B4e5 full 32-scene visual-motion review inventory

**Date:** 2026-11-06 IST. **Status:** Public original scientific source-art quality proof, **not approval and not newly created daily video output**.

## Why this is necessary

The latest user feedback was that Shorts reused a distracting continuously moving circular motif, and the long/Shorts design needs repeated visual polish. B4e4b source scene QA covered the original 32 scenes but visually retained only *seven* before/after comparison samples. B4e4c physically rendered two Shorts and a long with better floating original science art, but its retained image snapshots likewise sample just a few timestamps. A few sampled shots cannot show the actual composition and accidental repetition across the entire movie.

B4e5 is a **physical all-scene inspection pack**, not a model's invented design score. The script builds exactly three **public review contact sheets**: six scenes for the NASA Moon Short, twenty for the NIST file transfer long, and six for the USGS earthquake Short. They are all existing authored November 2026 science demonstration scripts, with a frozen **2026-11-12 source prototype date**, NOT facts freshly researched every day, not approved for YouTube, and not new weekly video content. This milestone does **not** increase the production-readiness score, change the owner/Branch 1 YouTube scheduling, or introduce a new AI provider.

## What is verified and what is not

For each of the 32 sourced beats, GitHub-hosted code physically renders native source SVG and the unboxed Pillow hero with correct editorial grid at actual source animation ticks **0, 60 and 120**. It computes exact source hero crop hashes and pixel-change fractions for both tick intervals and refuses identical/frozen source frames, repeated center-shot bit-identical scenes, malformed source claims, or changed release gate flags. The resulting metadata contains the **96 actual local source frames examined** and three contact sheets with source-linked scene title/metric labels. Source text/scene citation and editorial caption masks stay governed by B4e4a/B4e4b.

These motion measurements **cannot detect all circles or quantify distracting spinners**, cannot verify copyright, legibility from a phone, pacing, narration synchronicity, human preference or performance in YouTube Analytics. They never certify `automated_spinner_free_certification` or `human_creative_approval`. Repeated/spinner suspicion is surfaced as a mandatory human review question with no fabricated approval. A passing source-art sweep is also **not** a full human-watched encoded MP4.

The existing public scene hero may contain scientifically appropriate lunar/earthquake/data circular elements. Do not censor genuine science imagery just because a shape resembles a circle; the target is *repeated generic, unrelated motion*. The owner's continuing feedback loop should compare real 72-hour YouTube engaged-view retention against authentic analytics, not use view-counter loops as objective.

## GitHub execution and confidentiality

- New module `autopilot/visual_motion_review_v7.py` and regression tests `autopilot/test_visual_motion_review_v7.py` are pure-source, no AWS/Google/YouTube clients.
- New GitHub Actions `.github/workflows/flowminute-b4e5-32-scene-motion-review.yml` runs with only `contents: read`, `persist-credentials: false`, `PUBLISH_ENABLED=false`, zero paid model budget; it installs original local Pillow/CairoSVG rendering libraries and creates one real review artifact with **three PNG contact sheets + one redacted source metadata JSON**. No original owner device, raw user reference clip, third-party footage, private media, OAuth or production credentials.
- Source tests run in normal pytest; the expensive *physical 96-frame* test runs only in a dedicated GitHub Actions job via `FLOWMINUTE_B4E5_PHYSICAL_REVIEW=1`. The workflow then separately writes a second real source pack for independent artifact retention. It has **seven-day artifact expiry** and does not act as a permanent private escrow.
- Frozen fact/demo status, `real_youtube_uploads=0`, `daily_fresh_content_produced=false`, `release_authorized=false`, and five human review questions appear in the manifest.
- Any absence of original scene images, altered source claims, no motion, overflow or mismatch blocks successful completion.

## Remaining production path

Actual distinct **fresh** 2 Shorts + 1 long daily requires independent topic research and fact/rights review, secure human/owner release review, fully listened/watched final encoded media, real protected private cloud and OAuth/media vault, spending authorization, resumable Google publisher with post-upload readbacks, and 21 confirmed releases over seven laptop-off days. None of B4e5 unlocks those functions.

**Evidence accounting:** Existing estimated production readiness **40/100**; actual independently verified autonomous YouTube deliveries **0/21**. Public source-art quality is engineering progress, not evidence that owner production or revenue is live.
