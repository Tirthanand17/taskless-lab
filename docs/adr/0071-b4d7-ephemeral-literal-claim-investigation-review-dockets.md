# ADR-0071 — B4d7 source-anchored ephemeral claim-investigation passages

**2026-11-06 IST | Branch 2 | GitHub-only | NO FACTS VERIFIED | NO PUBLISH**

## Verified baseline and missing link

The successful trusted-main B4d6 workflow [42229757273](https://github.com/Tirthanand17/taskless-lab/actions/runs/42229757273) fetched **two directly readable articles**, linked them to **two of three** creative research outlines, and held one topic at RSS level. The three original creative research outlines contained source hashes and visual questions but **no text from the original publisher pages**. The optional script draft context still knew only headlines and hashes, so *no claim-level review could inspect what the actual webpage said*. A body SHA256 proves integrity of observed bytes, not semantic support for any sentence.

## Implementation

**`autopilot.public_article_passages`** is a small Python standard-library HTML paragraph extractor. It runs INSIDE the existing bounded `evidence_probe.probe_source` while it ALREADY has a validated 200 OK, exact-publisher HTTPS textual article response, **no additional network request**. It ignores scripts/nav/footer/aside, rejects suspicious secret/email/login/advertisement strings and stores at most **two independent literal passages of 60–140 characters each per source**. It records the literal normalized excerpt SHA256 and source paragraph index, marks every fragment **unverified** and **not licensed for video reuse**. Full article text and images are never saved. Some websites may deliver no readable paragraphs; the correct result is zero, never invented excerpts.

**`autopilot.evidence_probe`** has a strictly opt-in `--ephemeral-passages out/flowminute-ephemeral-source-passages.json` mode for the trusted GitHub foundation run only. The small transient passage collection sits in a separate **runner-local** file, never in the old source report, GitHub log, step summary, tracked repository or public GitHub Actions artifact. RSS-only observation still contains **zero** passages. New observation metadata explicitly reports whether a couple of literal snippets were temporarily held, while keeping `source_body_persisted=false` to distinguish these from retention of full source HTML. The original `source_text_or_image_stored=false` refers to **full article/image preservation**; transient tiny excerpts are separate and must always be deleted.

**`autopilot.ephemeral_claim_review_docket`** independently recomputes all three source-locked research outlines from original scout, three-slot source plan, editorial board and article observations. It cryptographically binds snippets to the observed full-article response SHA256 and the **specific planned video episode**. Forged source identity, larger-than-140-char quote, fabricated review approvals, altered snippet content without matching hash, citations attached to RSS-only articles, duplicate paragraph index or switched episode source fail closed. Output creates only **claim INVESTIGATION QUESTIONS** for human researchers: what atomic claim *if any* does this passage support and which second primary source corroborates it? Every proposed claim is unreviewed, factual/scripts/rights/media/YouTube flags stay FALSE. No AI provider, scraping bypass, copyrighted copied script or official factual assertion is produced.

The trusted-main daily foundation now creates this research docket *ephemerally* for three episodes, verifies the numeric counts and zero approvals, and deletes both temporary quoted-passage JSON and review-docket JSON on the unconditional `if: always()` cleanup. The existing two tiny publicly retained November research receipts remain **unchanged in scope**: article source counts, publisher types, hash IDs, release flags. A safety assertion rejects `literal_excerpt_unverified` in either public JSON. The new code lives in GitHub only, not the owner's laptop.

## Known limitations and follow-ups

- An HTML `<p>` can be navigation, promotional copy, incorrect, misleading, or scraped from a third party. The simple parser only finds a *literal candidate*; a reviewer must check actual page context, original publication date and responsible rights holder. An arXiv author's result is not automatically peer reviewed.
- Hash comparison is not a source signature nor independently corroborated truth. A malicious feed/page could still supply false text. The pipeline cannot accept a claim just because two snippets exist.
- These temporary excerpts are **not externally published, quoted in video, shipped to providers or used for automatically generated narration**. A later independent human claim validator with enrolled reviewer identities and rights review would be required. The existing `independent_fact_review_gate.py` is a cryptographic preflight only, not proof of human professional review.
- No new audio, 1080x1920 Short, long video, or owner-channel YouTube upload is created by this milestone. The source-only real video demonstrations remain separate. More media generation and protected publishing infrastructure is still required.
- Anonymous public GitHub runners are not private escrow: keep excerpts strictly ephemeral and minimal, do not count them as licensed source caches. Source publishers may deny automated retrieval; never evade bot protection or CAPTCHA.
