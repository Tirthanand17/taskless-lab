# ADR-0043 — B4e3 original cinematic scenes integrated into real Short and long videos

**Date:** November 5, 2026 IST. **Track:** Branch 2. **Status:** source changes and new real-render gate; not approved or live. Branch 1 untouched.

## Problem from latest owner screenshots

Owner again identified weak design and composition in the long and both Shorts. Even after the native ASS subtitle rescue, the static basic SVG graphics, visually repetitive 20-scene long video, modest scene depth, inadequate animated pacing and insufficient art direction remain unacceptable. Passing FFmpeg encoding, captions, frame hashes and audio technical checks does not mean the output is visually good. User demands side-by-side old/new visual comparisons and real complete videos, not further isolated test PNGs.

## Specific completed code change

- The fixed original renderer accepts a strict explicit opt-in visual_style cinematic_v3 in both _topic_png and render_full_topic_video. The default classic_v2 stays unchanged for historical regression and source-before art. Style cannot grant publish rights, modify existing source claims or import the uploaded third-party reference recording.
- The new cinematic_storyboard_v4 composes the already physically tested B4e2 original shaded 2.5D Earth/Moon, earthquake magnitude or perspective laptop objects into actual original NASA/NIST/USGS source frames. Individual source beat index chooses distinct modes: the 20-scene long rotates original laptop, dimensional file cards, bits/bytes comparison, conceptual unit path and abstract numeric chart; the two six-scene Shorts add source-specific clock/orbit/signal or seismic-wave/energy views. Each visual panel displays only the exact current signed authored source display_value; no new dynamic real-world claim.
- Artwork stays inside measured image-pane coordinates: portrait x74..1006 y533..1220 and landscape x130..1790 y280..720. B4e1 caption bands stay y1295..1570 portrait and y756..935 landscape. The compositor explicitly checks untouched pixels in the lower native subtitle area.
- retain_cinematic_three_v3 invokes real existing pinned Kokoro + FFmpeg full encode + independent AV review for both Shorts and the long. It stores source-invariant physical MP4, SRT and original-thumbnail hashes, independently extracted 4-second/16-second/midpoint and later long-video frames, plus a classic-before versus cinematic-after source frame comparison image for each format. All evidence remains unapproved, public, temporary; no reference clip, model weights, OAuth keys or commercial audio sampled.
- test_cinematic_storyboard_v4 runs physically drawn pixel/geometry comparisons and verifies 5 different long layouts, real moving Short frames, native caption safe zone and no fake imported third-party visual styles. New dedicated workflow flowminute-b4e3-cinematic-three-video-review.yml executes the physical tests on PRs; expensive 3-full-video CPU Kokoro render only after trusted main push or explicit owner dispatch.

## Objective proof and limits

Earlier B4e1 actually produced 2 redesigned original Shorts, archived under GitHub artifact 13394438672, with native ASS caption and original sound effects. B4e2 actually produced three original cinematic ART panels, artifact 13395161516. The two were NOT integrated in real moving 3-video deliverables. B4e3 closes that gap only when its dedicated main-branch run proves a non-expired actual 2-Short plus long MP4+SRT+thumb artifact and before/after comparisons from exactly the same source script. PR code/test passes alone do not count. Every physical MP4, image and SRT must match SHA and real native FFmpeg/caption scene QA.

The 2.5D artwork is procedural shaded PIL/CairoSVG illustration, not full 3D engine modeling and not a guaranteed cinematic 10/10. Legacy motion still uses five scene images per original timed scene; interpolated camera movement, 30fps independently animated objects, detailed texture/depth, natural speech quality and deliberate SFX ducking are future art tasks. The owner must actually watch/listen to each full result and evaluate typography, spacing, originality, pacing, voice, factual sources, voice/model/graphics rights and final script. Never silently convert a technically passing preview into publish authorization.

All real uploader/provider flags remain disabled. No YouTube channel OAuth, live scheduling or real publication, no cloud billing or local laptop use. Production rubric is still 40/100 and independently verified fully unattended YouTube uploads remain 0/21. User reference footage/audio never stored in PUBLIC repo. Reference production design cues are general only, no copied protected imagery, style markers or voice.
