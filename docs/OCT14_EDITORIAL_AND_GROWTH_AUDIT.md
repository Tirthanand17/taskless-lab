## Concrete growth upgrades and review plan

1. **Opening frame (0–1.5s).** No brand bumper before promise. Start with money/cart/form object and immediate contrast (FREE? / PAID? or START TASK? WAIT). Brand small in upper safe area.
2. **Visual demonstration not a wall of text.** Dynamic fictional browser/article/cart/plan UI with progress, deliberate zoom, clear contrast and mobile-safe text. Never pass a reconstruction off as actual Chrome footage. Avoid repetitive 8-second static headline cards.
3. **Narration.** Conversational question-reveal-payoff flow, segmented synthesis, varied micro-pauses, realistic levels, no fake human-voice claims. The full sound track still needs real human listening approval.
4. **One engagement request that is easy to answer.** Choose a relevant A/B question (1/2, FORM/CART), not generic 'please comment/subscribe/like' stacking. Reply meaningfully to genuine viewers; never manufacture engagement.
5. **Shorts → long-form funnel.** After Long 009 is uploaded, use Studio's **Related video** feature on both Shorts and pin useful context/long link if permitted. This cannot be assumed set by the Data API. Ask viewers which workflow they want tested next.
6. **Thumbnail.** Long form headline 'AI SHOPS FOR YOU?' with a prepared concept browser approval UI and subline FREE OR PAID?; no more than ~4 focal words; verify legible phone-size crop and source-rights of cinematic photo.
7. **Title/description.** Specific searchable value, India and feature eligibility only where substantiated. No false 'tested live' language. Put authoritative Google sources and one viewer prompt in description. No keyword stuffing.
8. **Measured experiment, not promises.** Compare next-day and 72h engaged Short views, Shorts stayed-to-watch and first-3s drop, average percentage watched, long-form impressions CTR, average view duration, comments per 100 engaged views and subscribers gained per 1000 engaged views. Do not use raw Shorts views alone; recent platform change counts from playback.
9. **Audience workflow.** Studio Q&A or Poll sticker only when natively supported in the Shorts editor; do not promise an API-uploaded Short includes those stickers. Reply to comments within 24h using genuine helpful answers. Consider making a video reply to a good real audience question.
10. **Posting times.** Preserve tested 11:00/16:00/20:30 IST as provisional slots, not known optimal windows; proper channel audience histogram unavailable and data too small. Test controlled time changes later, not all variables at once.
