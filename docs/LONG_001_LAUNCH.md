Why:

- promises the complete import fix rather than a cosmetic formatting trick.

## Description opening

Excel can remove leading zeros and change long numeric-looking identifiers when CSV data is interpreted as numbers. This tutorial shows the safer Power Query workflow: **Data → From Text/CSV → Transform Data → set identifier columns to Text → Close & Load.**

The tutorial also covers:
- long identifiers and Excel's 15-digit numerical precision limit;
- Automatic Data Conversions in current Microsoft 365 / Excel 2024;
- why custom number formatting can change appearance without preserving the underlying CSV value;
- when the TEXT formula is appropriate;
- how to inspect the exported CSV in a plain-text editor before uploading it elsewhere.
