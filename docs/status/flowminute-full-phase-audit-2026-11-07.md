## 4. Correctness gaps found during the audit

1. **Language drift in README:** prior text still claimed the daily workflow “does not generate finished videos” despite now physically generating all three unapproved rehearsal MP4s. The update should distinguish **generating ephemeral video** from **retaining reviewed/published video**. GitHub-hosted code is running; permanent private cloud is not.
2. **48 roles vs 48 agents:** `autopilot/agent_org.py` is explicit `STAGING ONLY`, no live LLM calls. Counting 48 independently acting agents as complete would be misleading.
3. **Audit only from source is insufficient:** `autopilot/project_phase_acceptance_audit_b4g6.py` adds a source-gate report with externally observed statuses explicitly marked `NOT_ESTABLISHED_BY_SOURCE_INSPECTION`. Unit tests assert the 12 source invariants and force failure on removed production environment checks. This **cannot self-issue GitHub success, Google OAuth, owner approval or real uploads**.
4. **CI green does not equal zero skipped tests:** media-enabled GitHub Daily Foundation installs Pillow/NumPy/soundfile/FFmpeg and exercises image/waveform tests, while lightweight Content Quality Gate may skip physical-media unit cases if optional packages are not installed. The B4g0 fix already corrected a prior false-green due to Pillow missing in the media foundation. Inspect per-job logs for any new skip regressions.
5. **Production security cannot be verified from YAML alone:** `environment: youtube-production`, a public-key variable and `PUBLISH_ENABLED` protection are source conditions; branch/environment protection configuration, effective OAuth scope and custody, owner key enrollment, GitHub role restrictions, paid cloud data/billing and live permissions require **owner-side external readback**.
6. **Historical Branch 1 snapshot is not live:** the observed Nov 5 schedule and the pre-upload rotating-arc diagnosis must not be represented as fixed or currently active without refreshed owner credentials and exact remote ID/readback.
